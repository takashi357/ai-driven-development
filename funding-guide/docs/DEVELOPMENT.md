# 開発と判断

記録日：2026-09-20

## 要件から実装まで

- 要件：国の制度を公式資料で調べ、事業に即した用途を増やし、操作によって結果が変わるようにする。
- 調査：厚生労働省・中小機構・NEDO・JST等の公式サイト・公募要領を照合。制度そのものの確認と、個別企業の資格確認を区別。
- 設計：自社／顧客／共同事業の受給者を分離。複数制度の最大額の合計は作らず、1つの事業に対する代替候補として比較。
- 実装：収録を11件から28制度・枠へ拡張。投資6区分、研修方式別の上限、年度残額を追加。従来の雇用収支は維持。
- 検証：13本の回帰テストと、ブラウザー上での23項目の画面操作による確認。単体テストの成功だけで画面の動作確認済みとは扱わない。

## 調査・検証による修正

1. 資本関係や企業規模を確認しないまま、中小企業向け制度を受給できると断定しないようにしました。大企業の判定条件も、全制度で共通化せず制度ごとに扱います。
2. 省力化投資補助金のカタログ型は旧上限を使わず、2026年3月以降の要領に基づく値を使用しました。
3. 旧・新事業進出補助金の受付終了と、新しい「新事業進出・ものづくり商業サービス補助金」の受付予定を区別しました。
4. 2026年8月の研修要件変更を反映し、汎用的なAIの概念やプロンプトだけを扱う研修を対象外に設定しました。
5. 研修人数を増やしたときの過大計算を防ぐため、事業所の年度上限1億円を反映し、既支給・計上済みの額も入力できるようにしました。
6. 通常枠の「150万円未満」を150万円に丸めないよう、円単位の差を保持しました。
7. 投資制度を切り替えたときに、前の制度で選んだ資格・特例の仮定を解除するようにしました。
8. 雇用助成の入金年が未定の場合は収支に算入せず、入金年を決めた年に1回だけ計上するようにしました。
