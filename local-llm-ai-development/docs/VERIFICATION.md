## 検証スクリプト

`tests/`の検証スクリプトは、Playwrightが取得する通常のChromiumで実行できます。

```sh
npm install
npx playwright install chromium
npm run test:diagnosis
npm run test:handoff
npm run test:offline
```

検査対象はローカルの`dist/`です。出力先は`test-results/`で、Git管理から除外しています。

## 前提と限界

診断の適性表示は提案・推定です。ブラウザーで機能が動くことと、組織の実務で有効であることは分けて評価してください。以下は検証していません。

- 実際の8GB／16GB PCでのモデル推論、応答速度、空きRAM、消費電力
- 日本語の実務品質、6B・7Bモデルと新しい小型モデルとの比較性能
- 複数人での同時利用、組織の文書管理との接続、長期運用
- 官公庁や企業の利用規程への適合、実データを用いた業務導入
- 人だけで作業した場合との費用・時間の比較
