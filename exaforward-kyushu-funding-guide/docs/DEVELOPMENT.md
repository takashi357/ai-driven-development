# 開発と判断

2026-09-20に、既存の地域DX・雇用助成サイトをエクサフォワード九州向けに拡張しました。

## 要件から実装まで

- 要件：国の制度を公式資料で調べ、会社に即した用途を増やし、結果が操作で変わるようにする。アクセス範囲を広げない。
- 調査：会社概要と適時開示、厚生労働省・中小機構・NEDO・JST等の公式サイト・公募要領を照合。設立発表の予定と会社概要の実績を区別。
- 設計：自社／顧客／共同事業の受給者を分離。補助金の合計最大額は作らず、1事業の代替候補を比較。
- 実装：11件から28制度・枠へ拡張。投資6区分、研修方式別上限、年度残額を追加。従来の雇用収支は維持。
- 検証：13本の回帰テストと23項目の実ブラウザ操作確認。単体テストだけで画面の動作確認済みとは扱わない。

## 調査・検証による修正

1. 設立発表の100％出資を確認し、自社が中小企業向け制度を受給できるという断定を防止。100％出資だけで全制度の大企業判定を共通化しない。
2. 省力化カタログ型の旧上限を使わず、2026年3月以降の要領を使用。
3. 旧・新事業進出補助金の受付終了と、新しい「新事業進出・ものづくり商業サービス補助金」の受付予定を区別。
4. 2026年8月の研修要件変更を反映し、汎用AI概念・プロンプトだけの研修を対象外に設定。
5. 研修人数増加時の過大計算を防ぐため、事業所の年度上限1億円と既支給・計上額を追加。
6. 通常枠「150万円未満」を150万円と丸めないよう、円単位の差を維持。
7. 投資制度を切り替えたら、前制度で選んだ資格・特例の仮定を解除。
8. 雇用助成の入金年未定は収支に算入せず、決めた年に1回だけ計上。

## 誰が何を判断するか

AIは調査支援、コード、テスト、説明資料を作成しました。採択可能性や会社の未公開情報は推定で補っていません。実際の申請では会社・申請者が事実資料をそろえ、対象経費・資格・着手時期・併用可否を窓口と確認します。

この開発記録は現在の成果物に対応します。未実行の検証や未確認の制度を完了扱いしません。
